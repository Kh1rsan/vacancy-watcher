# Поиск вакансий на HeadHunter

Скрипт периодически загружает открытые страницы поиска HH, фильтрует объявления и отправляет новые подходящие вакансии в Telegram. Для HeadHunter используется HTML-скраппинг, без его API; отправка выполняется через Telegram Bot API.

## Запуск

1. Установить Python 3.10 или новее.
2. В папке проекта выполнить `py -m pip install -r requirements.txt` (это установит `aiohttp` для асинхронных запросов).
3. Создать бота через `@BotFather` командой `/newbot`, написать новому боту `/start` и получить токен.
4. Создать файл .env с переменными среды:

   ```powershell
   TELEGRAM_BOT_TOKEN = "токен_от_BotFather"
   TELEGRAM_CHAT_ID = "ID_чата"
   ```

Программа сразу выполняет поиск, затем повторяет его раз в час. Оставьте окно консоли открытым. Для непрерывной работы после перезагрузки компьютера можно позже настроить Планировщик заданий Windows.

## Настройка

Откройте `config.json`. Для смены региона задайте `region_name` и соответствующий числовой `region_id` HH. Например, Омск сейчас задан как область HH `68`. Измените списки `training_keywords` и `welding_keywords`, если хотите расширить или сузить совпадения.

Скрипт запрашивает число страниц из `max_pages` и вакансий на странице из `per_page`. Значение `max_pages: 0` снимает лимит страниц со стороны скрипта: он идёт до пустой страницы или предела пагинации HH. Запросы выполняются асинхронно; число одновременных обращений задаётся параметром `concurrency`. В `sort_by` доступны `relevance` (по соответствию), `publication_time` (сначала новые), `salary_desc` (зарплата по убыванию) и `salary_asc` (по возрастанию). `search_period_days` задаёт давность публикации в днях: `0` — за всё время; также доступны `1`, `3`, `7` и `30`. Дополнительные фильтры обучения и ручной/дуговой сварки применяются, только если соответствующие списки в конфиге непустые.

Дубликаты отсекаются по ID вакансии или совпадению названия, работодателя и локации. Успешно отправленные вакансии хранятся в `telegram_sent_vacancies.json` и повторно не отправляются. Если отправка не удалась, скрипт попробует отправить вакансию в следующем цикле.
